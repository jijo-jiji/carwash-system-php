# carwash-system-php

How to run my code:

Download the ZIP from GitHub and extract it to C:\xampp\htdocs\carwash.

Turn on Apache and MySQL in XAMPP.

Go to localhost/phpmyadmin and create a new database named carwash.

Click the Import tab and select the carwash.sql file included in my project folder.

Now go to localhost/carwash/index.html.
